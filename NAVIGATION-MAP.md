```

        └─ Level 3: Section Menu (specific actions)
```

## 🎯 Design Principles

### 1. **Progressive Disclosure**
- Show only relevant options at each level
- Don't overwhelm with all features at once
- Guide users through natural paths

### 2. **Consistent Visual Language**
- Same emoji style throughout (glass bitmoji)
- Predictable patterns (status progressions)
- Clear hierarchy (categories → sections → actions)

### 3. **Quick Access**
- Most common actions in main menu
- 🎯 Quick Actions for power users
- Commands work from anywhere (`/search`, `/crypto`, etc.)

### 4. **Contextual Help**
- 💡 Tips appear when relevant
- ℹ️ Info messages guide new users
- 💡 Help accessible from main menu

### 5. **Visual Feedback**
- ⌛ Loading indicators
- ✅ Success confirmations
- ⚠️ Clear error messages
- Status emojis show progress
